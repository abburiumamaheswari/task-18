# Task 18 – Missing Values in Pandas

## Internship
Veda Technology – Data Science Internship

## Objective
To identify and handle missing values in datasets using Pandas.

## Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Topics Covered
1. Identifying missing values using `isna()`
2. Identifying available values using `notna()`
3. Counting missing values using `isna().sum()`
4. Removing missing values using `dropna()`
5. Filling missing values using `fillna()`
6. Handling missing values using Mean, Median and Mode
7. Cleaning student datasets
8. Handling missing values in the Titanic dataset
9. Exporting cleaned datasets into CSV files

## Datasets Used
- Student Dataset
- Titanic Dataset

## Learning Outcomes
- Understood missing values in Pandas.
- Learned different techniques to handle missing data.
- Practiced data cleaning and preprocessing.
- Created cleaned datasets and exported them into CSV files.

## Conclusion
Successfully completed Task 18 by identifying and handling missing values using Pandas. Learned how to clean datasets using different data preprocessing techniques.
